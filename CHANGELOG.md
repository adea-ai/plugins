## 2.0.0 (2026-09-26)

### Breaking changes

* The toolkit publishes as one package, `@adea-ai/plugins`, replacing
  `@adea-ai/catalog-core`, `@adea-ai/catalog-schema`, `@adea-ai/source-adapters`,
  and `@adea-ai/harness-adapters`. Every former entry point is still addressable
  through a subpath export: `./schema`, `./sources`, `./harness`,
  `./publication`, `./portable-catalog`, and `./agent-plugins{,/schema,/harness}`.
* The published catalog moves off GitHub Releases. A catalog is content
  addressed, so a release carrying one permanently outbid every versioned
  release for GitHub's single "latest" slot, and the repository's first listed
  release was a 64-character digest rather than a version. It is now published
  to the `catalog-assets` branch at `catalogs/<catalogId>/`, which is immutable
  by construction and readable cross-origin. See `docs/consumer-contract.md`.

### Features

* One plain `vX.Y.Z` release per change, matching `adea-ai/ui`. The
  `plugins-marketplace-vX.Y.Z` releases for the never-published private root
  manifest are gone, as is the `v1.0.0`-`v1.1.3` scheme abandoned on 2026-09-05.
